# 🛒 Sales Summary using SQLite and Python

This project demonstrates how to use **Python** and **SQLite** to generate, store, query, and visualize sales data.

---

## 📌 Objective

To extract basic sales information (like total quantity sold and total revenue per product) from a SQLite database and visualize the results using a **bar chart**.

---

## 📂 Features

- Creates a SQLite database with a sales table.
- Inserts **500 randomly generated sales records**.
- Executes SQL queries to calculate total quantity sold and revenue per product.
- Displays results using `print()` and a **matplotlib bar chart**.
- Saves the chart as `sales_chart.png`.

---

## 🛠️ Technologies Used

- Python 3.18
- SQLite (via `sqlite3` module)
- Pandas
- Matplotlib
- Jupyter Notebook or .py script

---

# Output:

-A Bar Chart Showing revenue per Product Category.
-A Bar chart Showing Total Qnty per Product.
